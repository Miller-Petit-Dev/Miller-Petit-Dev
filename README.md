## 🚀 About This Project

This repository hosts an **AI-augmented automated trading system** developed in Python and integrated with **MetaTrader 5 (MT5)**.

The project is not a simple trading bot.  
It is a **modular decision and execution system** designed to automate market analysis, strategy evaluation, risk management, and trade execution based on quantitative rules and data-driven logic.

The system reflects my approach as a **Software Engineer focused on solving complex problems through automation, system design, and intelligent tooling**.
